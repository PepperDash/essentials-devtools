# Tutorials - Learning-Oriented Guides

**"Take me by the hand and teach me"**

These tutorials are designed to take you from beginner to competent user through hands-on, step-by-step learning experiences. Each tutorial builds foundational knowledge and practical skills.

## 🚀 Getting Started

### [Getting Started Tutorial](./getting-started.md)
**Time**: 15-20 minutes | **Level**: Beginner

Your first steps with the PepperDash Essentials Web Config App. Learn to access the application, navigate the interface, and perform basic operations.

**You'll learn**:
- How to access the web application securely
- Navigate through all main sections
- Start your first debug session
- Apply basic filtering to find information
- View detailed message information

**Prerequisites**: Network access to a PepperDash Essentials processor

---

## 🔍 Core Features

### [Debug Console Tutorial](./debug-console-basics.md)
**Time**: 25-30 minutes | **Level**: Intermediate

Master the Debug Console - the most powerful feature for system monitoring and troubleshooting. Learn advanced filtering, message interpretation, and systematic troubleshooting approaches.

**You'll learn**:
- Advanced filtering and search techniques
- How to interpret different log levels and message types
- Managing debug sessions effectively
- Real-world troubleshooting scenarios
- Best practices for efficient debugging

**Prerequisites**: Completed Getting Started Tutorial

### [Device Management Tutorial](./device-management-basics.md)
**Time**: 20-25 minutes | **Level**: Intermediate

Learn to effectively browse, understand, and work with devices in your PepperDash Essentials system. Understand device types, relationships, and how to use device information for troubleshooting.

**You'll learn**:
- How to browse and identify devices
- Understanding device properties and capabilities
- Interpreting device types and their purposes
- Using device information for troubleshooting
- System organization and device relationships

**Prerequisites**: Completed Getting Started Tutorial

---

## 📚 Tutorial Learning Path

We recommend following this sequence for the best learning experience:

```
1. Getting Started Tutorial (Required)
   ↓
2. Debug Console Tutorial (Recommended)
   ↓  
3. Device Management Tutorial (Recommended)
```

**Estimated total time**: 60-75 minutes for complete foundational knowledge

## 🎯 Learning Objectives

By completing all tutorials, you will:

- ✅ **Navigate confidently** through all application features
- ✅ **Monitor systems effectively** using real-time debug information
- ✅ **Filter and search** large volumes of system messages efficiently
- ✅ **Identify and understand** system devices and their roles
- ✅ **Troubleshoot systematically** using proper techniques and tools
- ✅ **Integrate knowledge** across different application features

---

## 💡 Tutorial Design Principles

Our tutorials follow these principles:

**Hands-on Learning**: Every tutorial includes practical exercises with your actual system

**Progressive Complexity**: Start simple, build to more advanced concepts

**Real-world Focus**: Learn skills you'll actually use in daily work

**Success Validation**: Clear indicators to confirm you're learning correctly

**Practical Application**: Connect learning to real troubleshooting scenarios
